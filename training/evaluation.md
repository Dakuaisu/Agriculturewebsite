# Model evaluation

Generated by `python train.py` (scikit-learn 1.9.1). Do not edit by hand.

- Data: 2200 rows, 22 crops, 100 rows per crop
- Split: stratified 80/20, seed 42 (1760 train / 440 test)
- Model: Gaussian naive Bayes (scikit-learn defaults), trained on the train split only

Naive Bayes is shipped for simplicity, not accuracy. It is a mean and a variance per crop and
feature, so it is small and easy to run in the browser. On this split it makes 2 test
errors against 5 for the bagged trees: a gap of a few test errors, not evidence
that it is the better model.
