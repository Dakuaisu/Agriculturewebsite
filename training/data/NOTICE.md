# Dataset

`Crop_recommendation.csv` is the "Crop Recommendation Dataset" by Atharva Ingle,
published on Kaggle: https://www.kaggle.com/datasets/atharvaingle/crop-recommendation-dataset

Licence: Apache License 2.0, as listed in the dataset's Kaggle metadata.
The file is redistributed unmodified (150,034 bytes, 2,200 rows, SHA-256
`54a5a6e5408668e668667efc50de2fc867c1b875e0431b4f54dd331b0a109a4e`).

Kaggle describes the data as "built by augmenting datasets of rainfall, climate and
fertilizer data available for India". The augmentation method and the original
sources are not documented, so treat it as partly synthetic.
